Leonida Platinum is a free, offline web guide and tracker for all 55 Grand Theft Auto VI PlayStation 5 trophies: the official list with grades and hidden flags, a saved checklist with export and import, search and filters, a spoiler setting, a five-stage roadmap to the platinum, the missable trophies flagged, and a sourced guide for every trophy.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — no network needed, the app loads only its own files. `main.ts` (Node 22) copies `app/` and `screenshots/` to `/output` and writes `/output/dossier.json`.
